Diseño de página para ver el Clima

Descripción del Proyecto

Este proyecto consiste en una aplicación web sencilla desarrollada con HTML, CSS y JavaScript, que permite consultar el clima en tiempo real de cualquier ciudad. Para obtener la información meteorológica se utilizan APIs externas (como OpenWeatherMap), las cuales proporcionan datos actualizados sobre temperatura, humedad, velocidad del viento y condiciones generales. La interfaz está diseñada para ser intuitiva y responsiva, mostrando los resultados de manera clara y atractiva. El usuario ingresa el nombre de la ciudad en un campo de búsqueda, y mediante fetch en JavaScript se realiza la petición a la API, mostrando los datos directamente en la página.
